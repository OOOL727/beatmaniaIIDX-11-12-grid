# LAMP GRID

beatmania IIDX SP のスコアCSVを、非公式の地力難易度表（☆11 / ☆12）と重ねて、
クリアランプを色で一覧するビューアです。ブラウザだけで動き、読み込んだデータは
端末の外に出ません。

**個人が趣味で作った非公式ツールです。KONAMI およびその関連会社とは関係ありません。**

👉 https://oool727.github.io/beatmaniaIIDX-11-12-grid/

---

## できること

- ☆11 / ☆12 を、**NORMAL表**と**HARD表**それぞれで表示
- 地力帯ごとにランプをタイル表示し、達成率をバーで可視化
- **帯の見出しをタップ**すると、その帯の詳細（曲名・ランプ・傾向・BP）が開く
- **曲名検索**と**譜面傾向でのフィルタ**
- CSVを読み込むと、**前回からのランプ更新**を表示
- ランプ分布のグラフ
- **未プレーのおすすめ**（易しい地力帯から順に提示）
- **次に狙う譜面**（未達成の譜面を、後述の重み付けで並べ替え）

## 使いかた

公式サイトの「スコアデータCSVダウンロード」で取得したCSV（プレースタイル SP）を、
画面にドラッグするか、ボタンから選びます。

PCを使えない環境向けに、**テキストを貼り付けて読み込む**こともできます。
公式サイトのスコア一覧を見出しの行からコピーして貼り付けてください。
区切り文字（カンマ・タブなど）は自動で判別します。

読み込んだCSVは端末内（localStorage）に保存されるので、次回からは開くだけです。
差し替えたいときは「別のCSVを読み込む」、消したいときは「保存データを削除」。

スマホでは、ブラウザで開いたあと
iOS は 共有 →「ホーム画面に追加」、Android は メニュー →「アプリをインストール」で
アプリのように使えます。インストール後はオフラインでも起動します。

## 「次に狙う譜面」の並び順について

単純なBPの少ない順では、実態と噛み合わないことがあります。
たとえばラス殺し譜面は、BPが少なくてもゲージを最後に持っていかれるため、
地力が上がらないとクリアに届きません。

そこで、**並べ替えのときだけ**BPに重みを加えています。
**表に出るBPの数値は、常に記録どおりの実測値です。**

### NORMAL系ゲージ（A-EASY / EASY / NORMAL）を狙うとき

回復が大きいぶん「どこで削られるか」が効きます。

| 要素 | 重み |
|---|---|
| ラス殺し・終盤難・終盤発狂・後半難 | +50 |
| 前半難・序盤発狂・開幕発狂・中盤発狂 | -30 |

### HARDゲージを狙うとき

回復が薄いため、難所の位置は関係なく「難所があること」自体が不利です。
前半難のボーナスもありません。

| 要素 | 重み |
|---|---|
| ラス殺し・終盤難・局所難・発狂 などの難所 | +40 |

### ソフラン（共通）

「ソフラン」タグの重さは譜面によって大きく違うため、BPMの変化倍率で分けています。

| 変化倍率 | 重み |
|---|---|
| 2倍未満（微ソフラン） | 0 |
| 2〜4倍 | +20 |
| 4倍以上 | +40 |

### 皿（共通・任意）

連皿は個人差が大きく、運指によって有利にも不利にもなります。
既定では重みをかけず、**傾向の表示を黄色にするだけ**にしています。

「皿が苦手」にチェックを入れると、皿要素を含む譜面に **+40** の重みがかかり、
おすすめ順で後ろに回ります。

### 傾向の色

| 色 | 意味 |
|---|---|
| 赤 | 並び順で不利に働く要素 |
| 緑 | 有利に働く要素 |
| 黄 | 皿要素（個人差） |

## 難易度表データの出典

このツールに内蔵している地力難易度表は、以下のサイトで公開されているものを
書き起こして利用させていただいています。表の内容に関する議論・修正要望は、
本リポジトリではなく出典元をご参照ください。

**beatmania IIDX SP☆11 難易度表保管所(仮)**
https://w.atwiki.jp/bemani2sp11/

- ☆11 (新ハード難易度表) / ☆11 (新ノマゲ難易度表)
- ☆12 (ハード難易度表) / ☆12 (ノマゲ難易度表)

内蔵しているのは **2025-02-22 時点** の版です。それ以降に追加された楽曲は
表に載っていないため、本ツールでも表示されません。
また☆11ハード表は2023年7月以降スレの更新が止まっており、未定の楽曲が多く残っています。

問題がある場合は Issue でご連絡ください。速やかに対応します。

## 注意

- 未解禁の曲は、表にあってもCSV側に無いため未プレー扱いになります
- 曲名の表記ゆれにより、一部の譜面が照合できないことがあります
- 難易度の判定・並び順はあくまで目安です

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体。難易度表データを内蔵しているので単体で動く |
| `manifest.webmanifest` | アプリ名・アイコン・表示モード |
| `sw.js` | オフライン用キャッシュ（ネットワーク優先） |
| `icon-*.png` | ホーム画面アイコン |
| `iidx_sp11_table.csv` / `iidx_sp12_table.csv` | 難易度表データ（参照用） |

`index.html` を更新したときは、`sw.js` の `CACHE` の値を `v11`, `v12` … と
上げてください。新しい版に切り替わる合図になっています。
