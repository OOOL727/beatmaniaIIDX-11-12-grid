# LAMP GRID

beatmania IIDX SP のスコアCSVを、非公式の地力難易度表（☆11 / ☆12 ノマゲ）と重ねて、
クリアランプを色で一覧するビューアです。ブラウザだけで動き、読み込んだデータは
端末の外に出ません。

**個人が趣味で作った非公式ツールです。KONAMI およびその関連会社とは一切関係ありません。**

👉 https://ooool727.github.io/beatmaniaIIDX-11-12-grid/

---

## できること

- ☆11 / ☆12 を切り替えて、地力帯ごとにランプをタイル表示
- 帯ごとの達成率と、「どの帯まで半分埋まっているか」の目安表示
- 判定基準を A-EASY / EASY / ノマゲ / HARD で切り替え
- 未達成のうち、BPが記録されている譜面をBPの少ない順に一覧

## 使いかた

公式サイトの「スコアデータCSVダウンロード」で取得したCSV（プレースタイル SP）を、
画面にドラッグするか、ボタンから選びます。

読み込んだCSVは端末内（localStorage）に保存されるので、次回からは開くだけです。
差し替えたいときは「別のCSVを読み込む」、消したいときは「保存データを削除」。

スマホでは、ブラウザで開いたあと
iOS は 共有 →「ホーム画面に追加」、Android は メニュー →「アプリをインストール」で
アプリのように使えます。インストール後はオフラインでも起動します。

## ランプの色

| 色 | ランプ |
|---|---|
| ピンク（発光） | FULLCOMBO |
| 金 | EX-HARD |
| 白 | HARD |
| 水色 | ノマゲ |
| 緑 | EASY |
| 紫 | A-EASY |
| 赤 | FAILED |
| 暗灰 | 未プレー |

## 難易度表データの出典

このツールに内蔵している地力難易度表は、以下のサイトで公開されているものを
書き起こして利用させていただいています。表の内容に関する議論・修正要望は、
本リポジトリではなく出典元をご参照ください。

**beatmania IIDX SP☆11 難易度表保管所(仮)**
https://w.atwiki.jp/bemani2dx_sp11/

- [☆11 (新ノマゲ難易度表)](https://w.atwiki.jp/bemani2sp11/pages/22.html)
- [☆12 (ノマゲ難易度表)](https://w.atwiki.jp/bemani2sp11/pages/19.html)

内蔵しているのは **2025-02-22 時点** の版です。それ以降に追加された楽曲は
表に載っていないため、本ツールでも表示されません。

問題がある場合は Issue でご連絡ください。速やかに対応します。

## 注意

- 未解禁の曲は、表にあってもCSV側に無いため未プレー扱いになります
- 曲名の表記ゆれにより、一部の譜面が照合できないことがあります
- 難易度の判定はあくまで目安です

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体。難易度表データを内蔵しているので単体で動く |
| `manifest.webmanifest` | アプリ名・アイコン・表示モード |
| `sw.js` | オフライン用キャッシュ（ネットワーク優先） |
| `icon-*.png` | ホーム画面アイコン |

`index.html` を更新したときは、`sw.js` の `CACHE`（`lampgrid-v1`）の値を
`v2`, `v3` … と上げてください。古いキャッシュが残らなくなります。
