# LAMP GRID

beatmania IIDX の公式「スコアデータCSV」をブラウザ内で読み込み、
SP難易度表とクリアランプを重ねて確認するシングルページWebアプリです。

## 主な機能

- 公式スコアデータCSVのドラッグ＆ドロップ / ファイル選択 / テキスト貼り付け
- CSVはブラウザ内だけで処理し、外部へ送信しない
- SP ☆9 / ☆10 / ☆11 / ☆12 の難易度表表示
- NORMAL / HARD 系の難易度帯とクリアランプの重ね合わせ
- 次に狙う譜面の提案
- 適正 / 挑戦 / 安定地力の推定
- 試験版 Skill Rating
- Skill Rating Map による地力帯の色分け可視化
- 下位レベルのランプ埋め目標
  - 1つ下: HARD
  - 2つ下: EX-HARD
  - 3つ下以下: FULLCOMBO
- 譜面JOIN監査

## Skill Rating（試験版）

Skill Rating は公式指標ではなく、本アプリ独自の試験的な指標です。

- 適正☆の評価上位40譜面の平均を Base Rating とする
- 1つ下の☆は HARD 相当以上の高ランプ実績を小さく Bonus 加算
- 2つ下の☆は EX-HARD 相当以上の高ランプ実績をさらに小さく Bonus 加算
- 3つ下以下は Rating 対象外
- ☆12では Rating を地力帯 F- ～ A+ の目安へマッピングして表示

「適正」「挑戦」「安定」は Skill Rating とは別ロジックで算出します。

## 難易度表の出典

### ☆11 / ☆12

bemani2sp11 wiki の SP ☆11 / ☆12 難易度表を参照しています。

- https://w.atwiki.jp/bemani2sp11/

### ☆9 / ☆10

胡椒氏作成の以下の難易度表を、出典明記を条件に許可を得て加工・使用しています。

- 「ⅡDX ☆9,10ノマゲ以下難易度表」
- 「☆10ハード難易度表」

表の更新時は、新曲追加だけでなく既存曲のランク変更も反映する方針です。

## 譜面JOIN

譜面種別は A / H / L を区別して厳密に照合します。
明示された `(L)` 譜面がCSVに存在しない場合、同曲の A / H ランプを代用しません。

無印タイトルが特殊な最高譜面を指す既知ケースのみ、個別に譜面種別を解決しています。

## 公開版と開発版

公開用 `index.html` には、利用許可が確認済みのデータのみを含めます。

NASK氏版 ☆10 難易度表は `feature/nask-sp10` で開発し、
利用許可が確定するまでは公開版へ含めません。

## ローカル実行

`index.html` をブラウザで開くだけでも利用できます。
PWA / Service Worker の挙動まで確認する場合は、ローカルHTTPサーバー経由で確認してください。

```bash
python -m http.server 8000
```
