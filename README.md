# LAMP GRID

beatmania IIDX SP ☆9 / ☆10 / ☆11 / ☆12 のスコアデータを、非公式の地力難易度表と重ねて、
クリア状況を地力帯ごとに一覧表示するWebアプリです。

公式サイトから取得したスコアデータCSVを読み込むと、
FULLCOMBO / EX-HARD / HARD / NORMAL / EASY / A-EASY / FAILED / 未プレーを
色分けして表示します。

ブラウザだけで動作し、読み込んだスコアデータは端末内で処理されます。
サーバーへのアップロードは行いません。

👉 https://oool727.github.io/beatmaniaIIDX-11-12-grid/

**個人が趣味で制作した非公式ツールです。KONAMI およびその関連会社とは関係ありません。**

---

## できること

- ☆9 / ☆10 / ☆11 / ☆12 のクリア状況を表示
- **NORMAL表 / HARD表**を切り替えて表示
- 地力帯ごとにクリアランプをタイル表示
- 地力帯ごとの達成数・達成率を表示
- 選択したクリア目標を基準に、現在の地力帯の目安を表示
- **適正 / 挑戦 / 安定地力**を表示
- **試験版 Skill Rating** と色付き **Skill Rating Map** を表示
- 適正☆からの距離に応じたランプ埋め目標を表示（1つ下HARD / 2つ下EX-HARD / 3つ下以下FULLCOMBO）
- **帯の見出しをタップ / クリック**して、曲名・ランプ・譜面傾向・BPの詳細を表示
- **曲名検索**
- **譜面傾向による絞り込み**
- **未達成の譜面だけ表示**
- タイル上への**曲名表示**
- 前回読み込み時からの**ランプ更新数を表示**
- ランプ分布をグラフ表示
- **未プレーのおすすめ**
- 譜面JOIN監査（L未記録候補 / 要確認JOIN）
- **次に狙う譜面**
- 「皿が苦手」設定によるおすすめ順位の調整
- CSVをダウンロードしにくい環境向けの**テキスト貼り付け読み込み**
- 読み込んだデータや表示設定を端末内に保存
- PWAとしてホーム画面に追加し、オフラインでも起動

## 使いかた

### 1. スコアデータを読み込む

公式サイトの「スコアデータCSVダウンロード」で取得した、
**プレースタイル SP のスコアデータ**を使用します。

LAMP GRIDを開き、

- CSVを画面にドラッグ＆ドロップする
- 「CSVを選ぶ」からファイルを選択する

のどちらかで読み込めます。

読み込み対象は、CSV内の

- HYPER
- ANOTHER
- LEGGENDARIA

のうち、難易度が☆9～☆12の譜面です。

---

### 2. テキストを貼り付けて読み込む

スマートフォンなど、CSVファイルを扱いにくい環境では
**「テキストを貼り付ける」**から読み込むこともできます。

公式サイトのスコア一覧を、**「タイトル」などの見出し行を含めて**コピーし、
入力欄へ貼り付けてください。

カンマ、タブ、セミコロンなどの区切り文字は自動判別します。

---

### 3. ☆9 / ☆10 / ☆11 / ☆12 と表を選ぶ

画面上部から、

- ☆12
- ☆11
- ☆10
- ☆9

を切り替えられます。

さらに、

- **NORMAL表**
- **HARD表**

を切り替えて表示できます。

NORMAL表からHARD表へ切り替えた場合は、
クリア目標も自動的に「HARD以上」へ切り替わります。

☆10は胡椒氏作成のNORMAL系難易度表とHARD難易度表を使用します。
☆9は胡椒氏作成のNORMAL系難易度表を使用し、HARD難易度表はありません。

NASK氏版☆10は別の開発ブランチで対応中ですが、
利用許可が確定するまでは公開版に含めません。

## クリア目標

表示や達成率の基準として、次の4種類から選択できます。

| クリア目標 | 達成扱いになるランプ |
|---|---|
| A-EASY以上 | A-EASY以上 |
| EASY以上 | EASY以上 |
| NORMAL以上 | NORMAL以上 |
| HARD以上 | HARD以上 |

「未達成の譜面だけ表示」を有効にすると、
選択したクリア目標にまだ到達していない譜面だけを表示します。

このクリア目標は、後述する「次に狙う譜面」の選定にも使用されます。

---

## 地力帯の表示

各地力帯には、

- 達成譜面数
- 対象譜面数
- 達成率

が表示されます。

帯の見出しをタップ / クリックすると詳細が開き、

- 曲名
- 現在のクリアランプ
- 譜面傾向
- BP（ミスカウント）

を確認できます。

「曲名をマス上に表示」を有効にすると、
通常のランプタイルの代わりに曲名付きの表示になります。

## 実力の目安

LAMP GRIDでは、単一の数字だけでなく、
**適正 / 挑戦 / 安定**の3方向から現在地を表示します。

### 適正地力

A-EASY以上の達成率を中心に、
今メインで攻略する帯の目安を表示します。

判定では、ひとつ上の帯の実績を0.5倍、
ふたつ上を0.25倍……として加味し、
上位帯の実績による補正は最大+20ポイントまで反映します。

### 挑戦到達

A-EASY以上が**50%以上**に到達している最も高い地力帯を、
挑戦できている帯の目安として表示します。

### 安定地力

HARD以上が**30%以上**に到達している地力帯を、
安定して処理できる帯の目安として表示します。

適正☆で該当帯がない場合は、
ひとつ下の☆、さらにその下の☆へ順番に探します。

例：

```text
適正：☆12 地力F
挑戦：☆12 地力E
安定：☆11 地力E
```

いずれも非公式難易度表と手元のCSVから算出した
**LAMP GRID独自の目安**であり、正式な段位・地力認定ではありません。

## Skill Rating（試験版）

Skill Ratingは、
各譜面の難易度帯とクリアランプを数値化して作る
**LAMP GRID独自の試験的な総合指標**です。

### 譜面ポイント

レベル基礎値：

| レベル | 基礎値 |
|---|---:|
| ☆9 | 400 |
| ☆10 | 600 |
| ☆11 | 800 |
| ☆12 | 1000 |

同一レベル内では、難易度帯が1段上がるごとに基本的に **+25pt** します。

ランプ加点：

| ランプ | 加点 |
|---|---:|
| A-EASY | +0 |
| EASY | +25 |
| NORMAL | +50 |
| HARD | +100 |
| EX-HARD | +150 |
| FULLCOMBO | +200 |

### Base Rating

現在の適正☆にある譜面のうち、
評価値上位**40譜面**の平均をBase Ratingとします。

### 下位☆Bonus

下位レベルの高ランプ実績は、
Base Ratingへ直接混ぜず、小さなBonusとして加算します。

- 1つ下の☆：上位15譜面。HARD相当基準を超えた実績を反映（最大+20pt）
- 2つ下の☆：上位5譜面。EX-HARD相当基準を超えた実績を反映（最大+5pt）
- 3つ下以下：Skill Ratingの計算対象外

### Skill Rating Map

☆12帯では、Ratingを連続的な地力帯の目安として

```text
F- → F → E → D → C → B- → B → B+ → A- → A → A+
```

のように色付きゲージで表示します。

ゲージ上では、

- Base Rating
- 下位☆Bonus
- Bonus込みの最終Skill Rating

を分けて確認できます。

Skill Ratingの帯境界は現在も調整中です。
他プレイヤーの実績と比較しながら、今後変更する可能性があります。

## おすすめランプ

適正☆より下のレベルについて、
「次に何を埋めるか」をレベル差で表示します。

| 適正☆との差 | 推奨 |
|---|---|
| 1つ下 | HARD埋め |
| 2つ下 | EX-HARD埋め |
| 3つ下以下 | FULLCOMBO埋め |

例：☆12適正の場合

```text
☆12：適正帯を攻略
☆11：HARD埋め
☆10：EX-HARD埋め
☆9 ：FULLCOMBO埋め
```



## ランプの色

| 表示 | ランプ |
|---|---|
| 虹色グラデーション | FULLCOMBO |
| 赤～金グラデーション | EX-HARD |
| 白 | HARD |
| 水色 | NORMAL |
| 緑 | EASY |
| 紫 | A-EASY |
| 赤 | FAILED |
| 暗灰 | 未プレー |

FULLCOMBOとEX-HARDは、本家のランプ色を意識しつつ、
多数のランプを同時に表示しても見づらくならないよう、
**点滅させず固定グラデーション**で表示しています。

## 前回からのランプ更新

新しいCSVを読み込んだとき、
前回読み込んだデータと比較してランプが上がった譜面を集計します。

例：

```text
前回の読み込みから

HARD に上がった譜面 … 3
EX-HARD に上がった譜面 … 1
```

ランプが変化していない場合は、
「ランプの更新はありませんでした」と表示します。

新しく追加された譜面など、前回データに存在しなかった譜面は
ランプ更新数には含めません。

現在選択している☆9～☆12について、

- FULLCOMBO
- EX-HARD
- HARD
- NORMAL
- EASY
- A-EASY
- FAILED
- 未プレー

の譜面数と割合を表示します。

## 未プレーのおすすめ

現在の表にある**未プレー譜面**を、
基本的に易しい地力帯から順に表示します。

同じ地力帯の中では曲名順です。

最初は25件まで表示され、
候補がさらにある場合は「もっと見る」から25件ずつ追加できます。

曲名検索や譜面傾向による絞り込みを行っている場合は、
その条件もおすすめ一覧に反映されます。

# 「次に狙う譜面」について

「次に狙う譜面」では、

1. 選択した**クリア目標に未達成**
2. **BP（ミスカウント）が記録されている**

という2条件を満たす譜面を候補にします。

単純なBPの少ない順では、実際のクリアしやすさと噛み合わない場合があります。

たとえばラス殺し譜面はBPが少なくても、
最後にゲージを大きく削られることでクリアに届かない場合があります。

そこでLAMP GRIDでは、**おすすめの並び替えに使用する内部評価値だけ**に
譜面傾向による補正を加えています。

**画面に表示されるBPそのものは変更しません。  
常にCSVに記録された実測BPを表示します。**

---

## NORMAL系ゲージを狙う場合

対象：

- A-EASY
- EASY
- NORMAL

NORMAL系ゲージでは回復量が比較的大きいため、
「難所がどこにあるか」を考慮します。

### 不利になる要素

次の傾向を含む場合、並び替え用のBPに **+50** します。

- ラス殺し
- 終盤難
- 終盤発狂
- 後半難
- 終盤高密度乱打

### 有利になる要素

次の傾向を含む場合、並び替え用のBPから **-30** します。

- 前半難
- 序盤発狂
- 開幕発狂
- 開幕殺し
- 中盤発狂

前半で削られても、その後に回復できる可能性があるためです。

---

## HARDゲージを狙う場合

HARDでは回復が薄いため、
難所の位置に関係なく**難所そのものがあること**を不利として扱います。

次のいずれかを含む場合、並び替え用のBPに **+40** します。

- ラス殺し
- 終盤難
- 終盤発狂
- 後半難
- 終盤高密度乱打
- 前半難
- 序盤発狂
- 開幕発狂
- 開幕殺し
- 中盤発狂
- 局所難
- 局所発狂
- 発狂
- 中盤難
- 全体難

HARD狙いでは、NORMAL系のような
「前半難だから有利」という補正は行いません。

---

## ソフラン補正

「ソフラン」というタグだけでは影響の大きさを判断しにくいため、
内蔵データの**BPM変化倍率**を使って補正します。

| BPM変化倍率 | 補正 |
|---|---:|
| 2倍未満 | 0 |
| 2倍以上～4倍未満 | +20 |
| 4倍以上 | +40 |

2倍未満の微ソフランは、推薦順位では補正しません。

ソフラン補正が実際に加わる譜面では、
「次に狙う譜面」の傾向表示も赤になります。

---

## 「皿が苦手」

連皿・皿複合などは運指や得意不得意による個人差が大きいため、
通常状態ではおすすめ順位への補正を行いません。

その代わり、皿要素を含む傾向は**黄色**で表示します。

「皿が苦手」にチェックを入れると、
皿要素を含む譜面の並び替え用BPに **+40** し、
「次に狙う譜面」で後ろに回りやすくします。

対象として判定しているタグは以下です。

- 連皿
- 皿複合
- 皿絡み
- 高速連皿
- 24分連皿
- BSS
- MSS
- HBSS
- 皿
- 皿同時
- 皿同時押し

---

## 「次に狙う譜面」の傾向色

| 色 | 意味 |
|---|---|
| 赤 | 現在のクリア目標で、推薦順位に不利に働く要素 |
| 緑 | NORMAL系ゲージで、推薦順位に有利に働く要素 |
| 黄 | 皿要素（個人差） |

黄色の皿要素は、
「皿が苦手」がOFFの場合は色だけ表示され、順位には影響しません。

---

## 推薦順位の計算イメージ

たとえば実測BPが20の譜面の場合：

### NORMAL狙い・ラス殺し

```text
実測BP 20
+ ラス殺し 50
= 並び替え用評価値 70
```

画面に表示されるBPは **20** のままです。

### NORMAL狙い・前半難

```text
実測BP 20
- 前半難 30
= 並び替え用評価値 -10
```

### HARD狙い・局所難

```text
実測BP 20
+ 難所補正 40
= 並び替え用評価値 60
```

### 皿が苦手 + 連皿

```text
実測BP 20
+ 皿補正 40
= 並び替え用評価値 60
```

複数の補正条件に該当する場合は、それぞれの補正が加算されます。

最終的にはこの内部評価値が小さい譜面から並べ、
同値の場合は実測BPの小さい譜面を先に表示します。

最初は25件まで表示され、
候補がさらにある場合は「もっと見る」から追加できます。

## 検索・絞り込み

### 曲名検索

入力した文字列を曲名に含む譜面だけを表示します。

検索中は該当する地力帯の詳細も自動的に開きます。

### 譜面傾向

現在選択している表に実際に存在する譜面傾向から選択できます。

例：

- 乱打
- 階段
- CN
- 連皿
- ラス殺し
- ソフラン

など。

選択肢には、その傾向を持つ譜面数も表示されます。

曲名検索と譜面傾向フィルタは併用できます。

## データの保存

読み込んだスコアデータはブラウザの **localStorage** に保存します。

そのため、同じブラウザ・同じ端末であれば、
次回LAMP GRIDを開いたときに保存済みデータを自動で復元します。

以下の表示設定も保存されます。

- ☆9 / ☆10 / ☆11 / ☆12
- NORMAL表 / HARD表
- クリア目標
- 開いている地力帯
- 曲名をマス上に表示
- 未達成の譜面だけ表示
- 「皿が苦手」

スコアデータを更新したい場合は、

- 「別のCSVを読み込む」
- 「テキストで貼り替える」

を使用してください。

「保存データを削除」を押すと、
保存されているスコアCSVと読み込み日時を削除します。

## 注意事項

- 未解禁の楽曲は、難易度表に存在していてもスコアデータ側に存在しないため、未プレーとして扱われる場合があります
- 曲名の表記ゆれなどにより、一部の譜面を照合できない場合があります
- A / H / Lは別譜面として厳密に照合し、目的譜面がCSVにない場合に別譜面のランプを代用しません
- `(L)`譜面が難易度表に存在してもCSVにLレコードがない場合は、未解禁・未所持・未プレー候補として監査表示される場合があります
- 無印タイトルがANOTHER以外の最高譜面を意味する既知ケースのみ、個別の譜面種別補正を行っています
- 難易度表の評価や「実力の目安」は絶対的なものではありません
- 「未プレーのおすすめ」「次に狙う譜面」の順位はあくまで目安です
- BPや譜面傾向だけで実際のクリア難易度を完全に判定するものではありません

## Service Workerの更新

`index.html`、`manifest.webmanifest`、アイコンなど、
Webアプリ本体としてキャッシュしているファイルを更新した場合は、
`sw.js` のキャッシュ名を更新してください。

例：

```js
const CACHE = "lampgrid-v15";
```

↓

```js
const CACHE = "lampgrid-v16";
```

新しいキャッシュ名にすることで、
古いキャッシュが削除され、新しい版へ切り替わります。

### README.mdだけを変更した場合

**キャッシュ名を変更する必要はありません。**

`README.md` はLAMP GRIDのService Workerで事前キャッシュしている
Webアプリ本体のファイルではないためです。

したがって、READMEの文章だけを修正した場合は、

```js
const CACHE = "lampgrid-v15";
```

のままで問題ありません。

## プライバシー

スコアデータの解析はブラウザ内で行います。

読み込んだCSVや貼り付けたスコアデータは、
LAMP GRIDのサーバーへアップロードされません。

データの保持にはブラウザのlocalStorageを使用します。
