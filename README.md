# LAMP GRID

beatmania IIDX SP の公式スコアデータCSVを、非公式の難易度表と重ねて、
**クリアランプ・地力帯・次に狙う譜面・現在の実力目安**をまとめて確認するWebアプリです。

現在は **SP ☆9 / ☆10 / ☆11 / ☆12** に対応しています。

公式サイトから取得したスコアデータCSVを読み込むと、
FULLCOMBO / EX-HARD / HARD / NORMAL / EASY / A-EASY / FAILED / 未プレーを色分けして表示します。

ブラウザだけで動作し、読み込んだスコアデータは端末内で処理されます。
**CSVや貼り付けたスコアデータを外部サーバーへアップロードすることはありません。**

👉 https://oool727.github.io/beatmaniaIIDX-11-12-grid/

**個人が趣味で制作した非公式ツールです。KONAMI およびその関連会社とは関係ありません。**

---

## できること

- **SP ☆9 / ☆10 / ☆11 / ☆12** のクリア状況を表示
- 難易度帯ごとにクリアランプをタイル表示
- NORMAL系 / HARD系の難易度表を切り替えて表示
- 地力帯ごとの達成数・達成率を表示
- 帯の見出しをタップ / クリックして、曲名・ランプ・譜面傾向・BPなどを表示
- **曲名検索**
- **譜面傾向による絞り込み**
- **未達成の譜面だけ表示**
- タイル上への**曲名表示**
- 前回読み込み時からの**ランプ更新数を表示**
- ランプ分布を表示
- **未プレーのおすすめ**
- **次に狙う譜面**
- ☆11 / ☆12ではBP・譜面傾向・ソフラン・皿苦手設定を考慮したおすすめ
- ☆9 / ☆10では難易度表の帯を中心にしたおすすめ
- **適正 / 挑戦 / 安定地力**の推定
- **試験版 Skill Rating**
- Skill Ratingを色付きの**Skill Rating Map**として可視化
- 下位レベルのおすすめランプを表示
  - 適正の1つ下：HARD
  - 適正の2つ下：EX-HARD
  - 適正の3つ下以下：FULLCOMBO
- CSVを扱いにくい環境向けの**テキスト貼り付け読み込み**
- 読み込んだデータや表示設定を端末内に保存
- PWAとしてホーム画面に追加し、オフラインでも起動
- 難易度表とCSVの**譜面JOIN監査**

# 使いかた

## 1. スコアデータを読み込む

公式サイトの「スコアデータCSVダウンロード」で取得した、
**プレースタイル SP のスコアデータ**を使用します。

LAMP GRIDを開き、

- CSVを画面にドラッグ＆ドロップする
- 「CSVを選ぶ」からファイルを選択する

のどちらかで読み込めます。

現在は主に、

- HYPER
- ANOTHER
- LEGGENDARIA

の☆9～☆12譜面を難易度表と照合します。

---

## 2. テキストを貼り付けて読み込む

スマートフォンなど、CSVファイルを扱いにくい環境では
**「テキストを貼り付ける」**から読み込むこともできます。

公式サイトのスコア一覧を、**「タイトル」などの見出し行を含めて**コピーし、
入力欄へ貼り付けてください。

区切り文字は自動判別します。

---

## 3. ☆レベルを選ぶ

画面上部から、

- ☆12
- ☆11
- ☆10
- ☆9

を切り替えられます。

☆11 / ☆12では従来の地力表、
☆9 / ☆10では胡椒氏作成の難易度表を使用しています。

---

## 4. NORMAL系 / HARD系の表を選ぶ

対応しているレベルでは、

- **NORMAL系**
- **HARD系**

の難易度表を切り替えて表示できます。

☆9は現在、NORMAL系の難易度表を使用します。

---

# クリア目標

表示や達成率の基準として、クリア目標を選択できます。

代表例：

| クリア目標 | 達成扱いになるランプ |
|---|---|
| A-EASY以上 | A-EASY以上 |
| EASY以上 | EASY以上 |
| NORMAL以上 | NORMAL以上 |
| HARD以上 | HARD以上 |

「未達成の譜面だけ表示」を有効にすると、
選択したクリア目標にまだ到達していない譜面だけを表示します。

---

# 地力帯の表示

各地力帯には、

- 達成譜面数
- 対象譜面数
- 達成率

を表示します。

帯の見出しをタップ / クリックすると詳細が開き、

- 曲名
- 現在のクリアランプ
- 譜面傾向
- BP（ミスカウント）

などを確認できます。

「曲名をマス上に表示」を有効にすると、
通常のランプタイルの代わりに曲名付きで表示できます。

---

# ランプの色

| 表示 | ランプ |
|---|---|
| 虹色グラデーション | FULLCOMBO |
| 赤～金系グラデーション | EX-HARD |
| 白 | HARD |
| 水色 | NORMAL |
| 緑 | EASY |
| 紫 | A-EASY |
| 赤 | FAILED |
| 暗灰 | 未プレー |

FULLCOMBOとEX-HARDは、多数のランプを同時に表示しても見づらくならないよう、
点滅ではなく固定色・固定グラデーションを使用しています。

---

# 現在の適正

CSVを読み込むと、画面上部に現在の実力目安を表示します。

主な表示は、

- **Skill Rating**
- **適正**
- **挑戦**
- **安定**

の4項目です。

例：

```text
Skill Rating：1055（☆12 地力E相当）

適正：☆12 地力F
挑戦：☆12 地力E
安定：☆11 地力E
```

これらは同じ意味ではなく、それぞれ別の観点から実力を見ています。

---

## 適正地力

現在メインで攻略するのに適している帯の目安です。

単純に「一番上のクリア曲」だけを見るのではなく、
各地力帯の達成率を基準に判定します。

上位帯の実績も少量加味します。

---

## 挑戦到達

**A-EASY以上を50%以上達成している帯**を基準に、
現在どこまで挑戦可能かを見る指標です。

適正地力より上に出ることがあります。

---

## 安定地力

**HARD以上を30%以上達成している帯**を基準に、
安定して処理できる地力帯を表示します。

適正☆で条件を満たす帯がない場合は、
1つ下、2つ下……と下位レベルを探索します。

---

# Skill Rating（試験版）

Skill Ratingは、LAMP GRID独自の**試験的な数値指標**です。

公式の段位・レーティングではありません。

「地力表のどの帯をどのランプで埋めているか」を
連続した数値として扱うことを目的としています。

---

## 譜面ごとのRating

レベルごとに基礎値を設定しています。

| レベル | 基礎値 |
|---|---:|
| ☆9 | 400 |
| ☆10 | 600 |
| ☆11 | 800 |
| ☆12 | 1000 |

さらに、各レベル内の難易度帯ごとに **25pt** ずつ加算します。

クリアランプにも加点を行います。

| ランプ | 加点 |
|---|---:|
| A-EASY | +0 |
| EASY | +25 |
| NORMAL | +50 |
| HARD | +100 |
| EX-HARD | +150 |
| FULLCOMBO | +200 |

---

## Base Rating

現在の適正☆について、
**評価値の高い上位40譜面の平均**をBase Ratingとします。

一部の最高難度曲だけをクリアした場合より、
一定数の譜面で実績を出しているプレイヤーを評価する設計です。

---

## 下位☆Bonus

適正☆より下のレベルは、Base Ratingへ直接混ぜません。

代わりに、高ランプの実績だけを少量Bonusとして加えます。

### 1つ下の☆

- 上位15譜面
- HARD相当を基準
- 基準を超えた分の20%を反映
- 最大 **+20pt**

### 2つ下の☆

- 上位5譜面
- EX-HARD相当を基準
- 基準を超えた分の10%を反映
- 最大 **+5pt**

### 3つ下以下

Skill Ratingには加算しません。

つまり、

```text
Skill Rating = Base Rating + 下位☆Bonus
```

です。

---

## Skill Rating Map

☆12帯では、Skill Ratingを地力帯へ対応させて色付きゲージで表示します。

現在の試験的な区分は、

```text
F- → F → E → D → C → B- → B → B+ → A- → A → A+
```

です。

ゲージ上では、

- **Base Rating**
- **Bonus込みの最終Skill Rating**

を別々のマーカーで表示します。

たとえば、

```text
Base 1036
Bonus +19
Final 1055
```

なら、下位☆の高ランプ実績によって
Ratingがどの程度押し上げられているかを視覚的に確認できます。

この地力帯へのマッピングは現在**試験版**であり、
今後データを見ながら調整する可能性があります。

---

# おすすめランプ

現在の適正☆からの距離を基準に、
下位レベルで狙うランプの目安を表示します。

| 適正☆との差 | おすすめ |
|---|---|
| 1つ下 | HARD |
| 2つ下 | EX-HARD |
| 3つ下以下 | FULLCOMBO |

たとえば☆12適正なら、

```text
☆12：適正帯を攻略
☆11：HARD埋め
☆10：EX-HARD埋め
☆9：FULLCOMBO埋め
```

という形になります。

---

# 前回からのランプ更新

新しいCSVを読み込んだとき、
前回読み込んだデータと比較してランプが上がった譜面を集計します。

例：

```text
前回の読み込みから

HARD に上がった譜面 … 3
EX-HARD に上がった譜面 … 1
```

ランプが変化していない場合は、
「ランプの更新はありませんでした」と表示します。

# ランプ分布

現在選択しているレベルについて、

- FULLCOMBO
- EX-HARD
- HARD
- NORMAL
- EASY
- A-EASY
- FAILED
- 未プレー

の譜面数と割合を表示します。

# 未プレーのおすすめ

現在の表にある未プレー譜面を、
基本的に易しい難易度帯から順に表示します。

最初は一定件数まで表示し、
候補がさらにある場合は「もっと見る」から追加できます。

曲名検索や譜面傾向による絞り込みを行っている場合は、
その条件もおすすめ一覧へ反映されます。

---

# 「次に狙う譜面」について

「次に狙う譜面」は、
現在のクリア状況から次に攻略候補となる譜面を選びます。

☆11 / ☆12と☆9 / ☆10では、
使用している難易度表の性質が異なるため、推薦方法も分けています。

---

## ☆11 / ☆12

従来の地力表では、

1. 選択したクリア目標に未達成
2. BP（ミスカウント）が記録されている

譜面を候補にします。

単純なBP順だけでは実際のクリアしやすさと噛み合わない場合があるため、
**おすすめの並び替えに使用する内部評価値だけ**に譜面傾向の補正を加えます。

**画面に表示されるBPそのものは変更しません。  
常にCSVに記録された実測BPを表示します。**

---

## NORMAL系ゲージを狙う場合（☆11 / ☆12）

A-EASY / EASY / NORMALでは、
難所の位置を考慮して推薦順位を調整します。

### 不利になる要素の例

- ラス殺し
- 終盤難
- 終盤発狂
- 後半難
- 終盤高密度乱打

これらは並び替え用評価値へ加点し、
推薦順位を下げます。

### 有利になる要素の例

- 前半難
- 序盤発狂
- 開幕発狂
- 開幕殺し
- 中盤発狂

前半で削られても後半で回復できる可能性があるため、
NORMAL系では推薦順位を上げる方向へ補正します。

---

## HARDゲージを狙う場合（☆11 / ☆12）

HARDでは回復が薄いため、
難所の位置より**難所そのものが存在すること**を重視します。

局所難・発狂・全体難などを含む場合、
推薦順位を下げる方向へ補正します。

NORMAL系のような「前半難なので有利」という扱いは行いません。

---

## ソフラン補正（☆11 / ☆12）

「ソフラン」というタグだけでは影響度を判断しにくいため、
BPM変化倍率を使って推薦順位を補正します。

微ソフランは補正せず、
変化倍率が大きい譜面ほど不利に扱います。

---

## 「皿が苦手」（☆11 / ☆12）

連皿・皿複合などは個人差が大きいため、
通常は皿要素だけで推薦順位を下げません。

「皿が苦手」をONにした場合のみ、
皿要素のある譜面を推薦一覧で後ろへ回します。

皿要素は候補一覧上でも識別できるよう表示します。

---

## ☆9 / ☆10

☆9 / ☆10では、
胡椒氏版難易度表の**難易度帯そのもの**を中心に推薦します。

☆11 / ☆12のようなBP・ラス殺し・皿苦手補正をそのまま適用するのではなく、

- 現在攻略している帯
- その周辺の帯
- 地力 / 個人差
- NORMAL系 / HARD系

などを基準に候補を選びます。

---

# 検索・絞り込み

## 曲名検索

入力した文字列を曲名に含む譜面だけを表示します。

検索中は該当する難易度帯の詳細も開きやすくなります。

## 譜面傾向

現在選択している表に存在する譜面傾向から絞り込めます。

例：

- 乱打
- 階段
- CN
- 連皿
- ラス殺し
- ソフラン

など。

曲名検索と譜面傾向フィルタは併用できます。

# 譜面JOINについて

LAMP GRIDでは、
難易度表の譜面と公式CSVの譜面を曲名・譜面種別で照合しています。

譜面種別は、

- HYPER
- ANOTHER
- LEGGENDARIA

を区別します。

---

## 別譜面のランプは借りない

たとえば難易度表に

```text
A MINSTREL ～ ver. short-scape ～(L)
```

と書かれている場合、
LEGGENDARIA譜面のデータがCSVに存在しなくても、
同曲のANOTHER譜面のランプを代用しません。

明示された `(L)` / `(H)` は厳密に照合します。

未解禁・未所持・未プレー等でCSVに該当譜面が無い場合は、
その譜面を未記録として扱います。

---

## 無印タイトルの特殊ケース

難易度表では、一部の曲で譜面種別が明示されていなくても
ANOTHER以外の最高譜面を指している場合があります。

現在、既知の特殊ケースとして明示的に処理しているものは、

- `Summer Vacation(CU mix)` → HYPER
- `THE SAFARI` → HYPER
- `おおきなこえで` → LEGGENDARIA

です。

これは「別譜面のランプを借りる」処理ではなく、
**難易度表上のタイトルがどの譜面を指すかを解決する処理**です。

---

## 譜面JOIN監査

CSV読み込み時に、
難易度表とスコアデータの照合状態を確認できます。

現在は主に、

- L譜面が難易度表にあるがCSVには未記録
- 難易度表とCSVで別譜面しか見つからない

といったケースを監査します。

L未記録は必ずしも異常ではなく、
未解禁・未所持・未プレー等の可能性があります。

---

# データの保存

読み込んだスコアデータはブラウザの **localStorage** に保存します。

そのため、同じブラウザ・同じ端末であれば、
次回LAMP GRIDを開いたときに保存済みデータを自動で復元します。

表示設定も一部保存します。

スコアデータを更新したい場合は、

- 「別のCSVを読み込む」
- 「テキストで貼り替える」

を使用してください。

「保存データを削除」を押すと、
保存されているスコアデータを削除できます。

# 注意事項

- 未解禁の楽曲は、難易度表に存在していてもCSV側に該当譜面が無く、未プレーとして扱われる場合があります
- 曲名・譜面表記の差異により照合できないケースが発生する可能性があります
- JOIN監査でL未記録と表示されても、必ずしもデータ異常とは限りません
- 難易度表の評価は絶対的なものではありません
- Skill Rating・適正・挑戦・安定はすべてLAMP GRID独自の目安です
- 「未プレーのおすすめ」「次に狙う譜面」の順位はあくまで参考値です
- BP・ランプ・譜面傾向だけで実際のクリア難易度を完全に判定するものではありません

# Service Workerの更新

`index.html`、`manifest.webmanifest`、アイコンなど、
Webアプリ本体としてキャッシュしているファイルを更新した場合は、
`sw.js` のキャッシュ名を更新してください。

例：

```js
const CACHE = "lampgrid-v15";
```

↓

```js
const CACHE = "lampgrid-v16";
```

新しいキャッシュ名にすることで、
古いキャッシュが削除され、新しい版へ切り替わります。

## README.mdだけを変更した場合

**キャッシュ名を変更する必要はありません。**

READMEはService Workerの事前キャッシュ対象ではないためです。

# プライバシー

スコアデータの解析はブラウザ内で行います。

読み込んだCSVや貼り付けたスコアデータは、
LAMP GRIDのサーバーへアップロードされません。
